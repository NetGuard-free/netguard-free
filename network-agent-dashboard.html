KONTROLA DOSTĘPU I MONITORING
ℹ TRYB: MONITOR SIECI
NetGuard w trybie standardowym (instalacja na komputerze) monitoruje sieć i wykrywa zagrożenia, ale nie blokuje ruchu sieciowego innych urządzeń. Funkcje oznaczania urządzeń jako zablokowane lub ustawiania harmonogramów są zapisywane w dashboardzie — pełna blokada sieciowa działa dopiero gdy NetGuard jest uruchomiony jako brama sieciowa (NanoPi R2S / RPi przed routerem).

INSTALACJA LOKALNEGO AGENTA PYTHON
Pełny agent Python działa wyłącznie lokalnie w Twojej sieci. Żadne dane nie opuszczają routera/komputera. Pobrany skrypt netguard_agent.py zawiera wszystkie moduły monitorowania.
WYMAGANIA SYSTEMOWE
✓ Python 3.9+
✓ Linux / macOS / Windows (WSL2)
✓ Dostęp do sieci lokalnej (LAN)
✓ Uprawnienia root/administrator
○ Opcjonalnie: Ollama + Llama3 (lokalny LLM)
○ Opcjonalnie: Home Assistant
ARCHITEKTURA AGENTA
netguard_agent.py
├── NetworkScanner — skanowanie ARP
├── PacketAnalyzer — analiza ruchu
├── ThreatDetector — wykrywanie zagrożeń
├── AIAnalyst — lokalny LLM (Ollama)
├── AlertManager — powiadomienia
└── WebDashboard — ten interfejs
SZYBKI START
# 1. Instalacja zależności
pip install scapy psutil flask flask-cors requests python-dotenv manuf
# 2. Uruchomienie agenta (tryb standardowy)
sudo python3 netguard_agent.py
# 3. Opcjonalnie: z lokalnym LLM (Ollama)
ollama pull llama3.2
sudo python3 netguard_agent.py --llm --model llama3.2
